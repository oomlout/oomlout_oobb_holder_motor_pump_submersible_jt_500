# JT-500 assembly book and viewer

The [part README](../../parts/oobb_holder_motor_pump_submersible_jt_500/README.md#assembly) contains the six illustrated steps. Edit their wording, hardware and order in [the populate file](../../working_oomp_populate.py). The inventory accounts for three printed pieces, one pump, six M3 screws, six M3 nuts and six M6 nuts.

Blender builds each step from the production meshes and the hardware introduced so far. The booklet uses the Oomlout wave-drive layout. The offline viewer embeds the eight rendered PDF pages and their hardware links using the [OOBB page template](https://github.com/oomlout/oomlout_oobb_version_5/blob/main/presentation/templates/assembly_page_viewer.html). It opens on steps 1–4. On a phone, use Zoom and pan across the landscape page.
